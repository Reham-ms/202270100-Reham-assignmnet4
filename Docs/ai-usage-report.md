# AI Usage Report

## Tools Used & Use Cases
### ChatGPT
I used ChatGPT to:
- plan the structure of the portfolio website
- understand how to implement GitHub API integration
- improve JavaScript logic for filtering, sorting, and validation


### GitHub Copilot
I used GitHub Copilot in WebStorm for:
- code suggestions
- completing repetitive HTML and JavaScript patterns
- speeding up small syntax tasks

## Benefits & Challenges
AI tools helped me:
- save time during planning and coding
- understand how to organize JavaScript into reusable functions
- improve the quality of documentation

Challenges included:
- some AI suggestions were too general
- I had to review code carefully to make sure it matched assignment requirements
- I had to modify generated code to fit my own project structure and naming

## Learning Outcomes
Through using AI tools, I learned:
- how to fetch data from an external API using `fetch()` and `async/await`
- how to validate form inputs using JavaScript
- how to manage theme state with `localStorage`
- how to break a web application into smaller logical functions

## Responsible Use & Modifications
I reviewed all AI-generated suggestions before adding them to my project. I changed variable names, improved structure, tested the code manually, and made sure I understood how each part worked.
